Jon PA Privacy Policy

Last updated: 5 October 2026

Jon PA is a private personal assistant application operated by Jonathan Seeff solely for his own Google accounts. It has no public users.

Data accessed

With the account owner's authorisation, the application accesses Google Mail, Google Calendar, Google Drive and Google Tasks data belonging to the account owner, in order to summarise, draft, schedule and file items on his instruction.

Use and sharing

Data is processed only to provide the assistant's functions to the account owner. It is not sold, shared with third parties, or used for advertising. Processing runs on the operator's own automation workspace and AI model providers acting under contract, and only the content needed for the requested task is sent.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Operational logs are kept only as long as needed to run the assistant. Access can be revoked at any time at myaccount.google.com/permissions, after which no further data is accessed.
